How to get a free Groq API Key

  1. Go to the official Groq Console website link below.
  2. Sign up or log into a free account.
  3. Navigate to the API Keys section on the left menu track.
  4. Click Create API Key, name it "Munchy", and copy it.
  5. Paste it here into Munchy Sous Chef! It saves securely directly on your device storage.
Check Sous Chef's recipes before making them. As it is AI, it can make mistakes. In the event of something bad ocurring because of Sous Chef, Gabyface910 is not responsible. Need a key? Generate one at the console.groq.com panel dashboard.
